# Day 04 deck style — "Project Proposal" template (user sample: sample_ppt_template.jpeg)

Match the pasted template exactly.

## Fonts (installed, use as-is)
- **Headings: Oswald Bold**, ALL CAPS, large, tight tracking (the template's signature condensed bold).
  Installed at day04_playbook/fonts/Oswald-*.ttf and registered in HKCU fonts.
- Sub-labels / small caps: Oswald SemiBold / Medium.
- Body: a clean small sans (Oswald Light or Segoe UI), small, muted grey.

## Palette
- Background: warm cream / bone `#E8E1D2` (cards same, or slightly lighter `#EFEADD`)
- Dark slides / blocks: near-black charcoal `#262320`
- Text on cream: `#262320`; text on dark: `#E8E1D2`
- Accent: small **orange** bar/dot `#E8622A` used VERY sparingly (one accent per slide, like the template's top bar)
- Muted body text: `#8A8176`

## Layout motifs (from the sample)
- Slide 1 cover = dark charcoal slide, huge "TITLE / subtitle" in Oswald Bold cream, tiny byline, a small orange bar top-center.
- Numbered items = thin-outline **circles** with 01/02/03/04 inside (Project Concept / Project Stages).
- Timeline = horizontal line with circular icon nodes + Phase 01..06 labels.
- Stats = big Oswald number ("13M+", "98%") + small caption.
- Alternating cream / dark charcoal slides for rhythm.
- B&W imagery in rectangles (for us: the CaveFlyer / agent game frames, desaturated or as-is).
- Bar chart for data (Target Audience style).
- "THE END" closing slide = dark, giant Oswald.

## Carry-over rules
- Slide 1 doubles as Upwork thumbnail: product name huge + one hook + strong visual. Crop-safe.
- Export each slide 1920x1080 PNG + PDF from a real .pptx.
- Confident, positive copy; numbers measured.
